# skills

Claude Code development-workflow plugins, one per topic, and standalone skills, by Dominykas Grubys.

- `dev-workflow`: the topic-agnostic specify, plan or architect, implement loop run by reviewed subagents in feature worktrees, plus `how` and `why` for reading a codebase. Works on its own; agents pick up whatever skills are installed.
- `macos-dev-workflow`: the workflow for macOS and iOS apps. Installs the core and adds the Apple platform skills.
- `skills/`: standalone skills installable with `npx skills add domasgru/skills`.

The repo is being set up. See [PLAN.md](PLAN.md) for the design and implementation plan.
